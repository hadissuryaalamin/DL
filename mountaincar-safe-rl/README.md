# MountainCar Safe RL — DQN, PPO, Safe PPO

Reproducible study of three RL agents on `MountainCar-v0`, culminating in **Safe PPO**
(a dual-critic PPO-Lagrangian agent that respects a soft proportional speed constraint
expressed as a Constrained MDP). Companion code for the paper in `paper/main.pdf`.

## Project structure

```
mountaincar-safe-rl/
├── src/
│   ├── envs.py              # ShapedMountainCar, ConstrainedMountainCar
│   ├── networks.py          # QNetwork, PPONetwork, SafePPONetwork (dual-critic)
│   ├── buffers.py           # DQNReplayBuffer, PPORolloutBuffer, SafePPORolloutBuffer
│   ├── utils.py             # seeding, JSON logging
│   └── agents/
│       ├── dqn.py           # train_dqn(seed, cfg, log_dir)
│       ├── ppo.py           # train_ppo(seed, cfg, log_dir)
│       └── safe_ppo.py      # train_safe_ppo — Phase 3 novelty
├── scripts/
│   ├── run_dqn.py           # python -m scripts.run_dqn --seed 0
│   ├── run_ppo.py
│   ├── run_safe_ppo.py
│   └── run_all.py           # python -m scripts.run_all --seeds 0 1 2
├── configs/
│   ├── dqn.yaml
│   ├── ppo.yaml
│   └── safe_ppo.yaml
├── notebooks/
│   └── analysis.py          # aggregates results/, regenerates figures
├── results/                 # {algo}/seed_{s}/metrics.json (+ checkpoint .pt)
├── videos/                  # MP4 recordings of training & greedy rollouts
├── paper/
│   ├── main.tex             # NeurIPS-style article
│   ├── main.pdf             # compiled paper
│   ├── references.bib
│   └── figures/             # PDF + PNG figures (regenerated by analysis.py)
├── requirements.txt
└── README.md
```

## Setup

```bash
python -m venv .venv && source .venv/bin/activate     # Linux/macOS
# or:    .venv\Scripts\activate                        # Windows

pip install -r requirements.txt
```

Tested on Python 3.14. CPU is fine — full sweep takes well under 2 hours.

## Reproduce all experiments (3 seeds × 3 algorithms)

```bash
python -m scripts.run_all --seeds 0 1 2
```

Or run individual algorithms:

```bash
python -m scripts.run_dqn      --seed 0
python -m scripts.run_ppo      --seed 0
python -m scripts.run_safe_ppo --seed 0
```

Each run writes `metrics.json` + checkpoint to `results/<algo>/seed_<s>/`.

## Regenerate figures from results

```bash
python notebooks/analysis.py
```

Reads every `results/<algo>/seed_*/metrics.json`, computes mean±std bands across seeds,
and writes PDF + PNG figures to `paper/figures/`.

## Build the paper

```bash
cd paper
pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
```

## Current state of `results/`

`results/<algo>/seed_0/metrics.json` was bootstrapped by parsing the logged training output
of the original `MountainCar_main.ipynb` notebook (sparse logging: every 30 episodes for DQN,
every 5 epochs for PPO/Safe PPO). After running `scripts/run_all.py` locally these are
overwritten with full per-episode/per-epoch logs, and `analysis.py` will produce multi-seed
plots with error bands.
